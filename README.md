# E-commerse-sale-dashboard-
GitHub Project Description
📊 Ecommerce Sales Analytics Dashboard

This project focuses on extracting ecommerce product data from public web pages using Python web scraping techniques and visualizing insights through an interactive Power BI dashboard.

🚀 Features
Web scraping using BeautifulSoup
Custom ecommerce dataset generation
100 rows of sales data
Interactive Power BI dashboard
Sales and profit analysis
Customer and category insights
🛠 Technologies Used
Python
Requests
BeautifulSoup
Pandas
Power BI
📌 Dataset Includes
Customer Name
Product Name
Category & Sub-Category
Amount
Profit
Quantity
State
Payment Method
Month
📈 Dashboard Insights
Top-performing states
Best-selling categories
Profit analysis
Payment method trends
Customer purchasing behavior
